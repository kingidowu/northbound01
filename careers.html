Career guides

Remote tech career guides

Salaries, skills, certifications, and how to break into the most in-demand remote IT, cloud, security, and healthcare-tech roles across the US & Canada.

Cloud

Cloud Engineer

$105,000 - $160,000

Cloud engineers design, build, and maintain the infrastructure that runs applications on AWS, Azure, or Google Cloud.

DevOps Engineer

$110,000 - $170,000

DevOps engineers automate how software is built, tested, and shipped, bridging development and operations with CI/CD pipelines, infrastructure as code, and cloud platforms..

Cloud Architect

$140,000 - $210,000

Cloud architects design the high-level cloud strategy and systems for an organization, balancing performance, security, and cost.

Site Reliability Engineer

$125,000 - $190,000

Site reliability engineers (SREs) keep large-scale systems fast and reliable using automation, monitoring, and software engineering practices.

IT

IT Support Specialist

$45,000 - $70,000

IT support specialists keep an organization's hardware, software, and users running smoothly.

System Administrator

$65,000 - $100,000

System administrators manage servers, networks, and IT infrastructure that keep a company running.

Network Engineer

$75,000 - $120,000

Network engineers design, build, and maintain the networks that connect an organization.

Help Desk Technician

$40,000 - $60,000

Help desk technicians are the first line of IT support, resolving user issues and learning the fundamentals that lead to nearly every other tech career.

Security

Cybersecurity Analyst

$85,000 - $130,000

Cybersecurity analysts protect organizations from threats by monitoring systems, investigating incidents, and hardening defenses.

Healthcare IT

Epic / EHR Analyst

$70,000 - $110,000

Epic and EHR analysts configure and support electronic health record systems that hospitals and clinics run on.

Healthcare Data Analyst

$70,000 - $105,000

Healthcare data analysts turn clinical and operational data into insights that improve care and efficiency.

Clinical Informatics Specialist

$85,000 - $125,000

Clinical informatics specialists sit between clinicians and IT, improving how technology supports patient care.
